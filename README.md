# 周琮評 Charles｜公開宣傳分身頁

這是一個 **GitHub Pages 的公開宣傳小名片**，不是官網本身。

## 這頁做什麼

原本兩個網站放在有分享碼門禁的託管空間，搜尋引擎的爬蟲沒有分享碼、進不去，站內 SEO 做得再完整也不會被收錄。這一頁放在公開的 `github.io`，讓爬蟲有個能讀的入口，真人再從這裡點進原本的網站。

- 星火聯播網：<https://lianbo-net.app.workbuddy.host/?sharecode=EWVMECBXGX>
- 本站：<https://charles630811-lang.github.io/>

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 唯一的頁面，所有文字與樣式都在這一支檔案裡 |
| `og-cover.png` | 給 Facebook / LINE 等轉貼時看的預覽圖 |
| `favicon.svg` | 瀏覽器分頁的小圖示 |
| `robots.txt` | 告訴爬蟲可以讀 |
| `sitemap.xml` | 給搜尋引擎的頁面清單 |
| `llms.txt` | 給 AI 搜尋讀的純文字摘要 |
| `.nojekyll` | 告訴 GitHub 不要用 Jekyll 重新加工，直接照檔案發布 |

## 三條規矩（對應新手最常踩的坑）

1. **這裡不放任何機密**：沒有後台網址、管理員信箱、金鑰與任何內部文件。整個倉庫是公開的，放進去等於給全世界看。
2. **這裡不放來路不明的素材**：人物照片、外部字型、第三方腳本都不用，避免授權說不清，也避免載入追蹤程式。
3. **這裡不收集資料、不做交易**：沒有表單、沒有付款、沒有會員登入。GitHub Pages 的條款不適合拿來經營交易網站，這頁只做介紹與導引。

## 怎麼改

改 `index.html` 裡的文字，存檔後推上 `main`，約 1～2 分鐘會更新。改完記得同步更新 `sitemap.xml` 的 `lastmod` 與頁面上的「最後更新」日期。

原始專案與完整內容放在另一個**私有**倉庫，這裡只放可以公開的檔案。

## 想改成自己的網域

日後買了自有網域，在這個倉庫根目錄新增一個名為 `CNAME` 的純文字檔，內容只寫網域名稱（例如 `www.example.com`），再到網域商那邊加一筆指向 `charles630811-lang.github.io` 的 CNAME 紀錄即可。現在沒有自有網域，**不要預先建立 `CNAME` 檔**，否則 GitHub 會找不到對應網域而回 404。
